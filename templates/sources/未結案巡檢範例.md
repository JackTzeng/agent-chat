# 📊 未結案巡檢（照 Codex 的 weekly-open-cases-report Skill）：系統先判斷好每一列有沒有結案，再交給 AI 回報
網址: https://docs.google.com/spreadsheets/d/把這裡換成控制總表的網址
模式: 未結案
# 分頁：報告上的名稱 = 找分頁的關鍵字（+ 表示名稱同時含這些字；有好幾頁時挑今年的，明年換頁不用改）
分頁: 一廠異常INC = 一廠+INC, 一廠偏差DE = 一廠+DE, 一廠CAPA = 一廠+CAPA, 一廠OOS = 一廠+OOS, 三廠INC = 三廠+INC, 三廠DE = 三廠+DE, 三廠CAPA = 三廠+CAPA, 三廠OOS = 三廠+OOS, 全廠CC = 一二三廠+CC
# 結案判斷：編號有刪除線＝作廢不算；狀態完全等於「結案」＝已結案；實際結案日欄（從右邊找第一個符合的）有值＝已結案；其餘＝未結案
編號欄: 編號, 單號, NO
狀態欄: 狀態
結案字: 結案
結案日欄: 實際完成日, 異常排除日, 實際結案, 結案日期
不算結案日: 應結案, 預計, 預定
期限欄: 應結案
# 想指定每件要列哪些欄，加幾行「欄位: 標題名稱」；不寫就自動挑：編號、主旨／說明、負責人、應結案日、狀態
# 關鍵字：訊息提到這些字才附上這份表（省 AI 額度）；寫「*」＝每則都附
關鍵字: 未結, 結案, 案件, CAPA, OOS, INC, DE, CC, 偏差, 異常, 變更, 追蹤, 巡檢
---
- 這份表是「每周未結案件巡檢」：被問到未結案、CAPA、OOS、DE、INC、CC 的進度，就照系統整理好的九個區段回答，不要自己重算件數。
- 先列彙總：九個區段各幾件、合計幾件；沒有未結案的區段寫「全部已結案」，九個區段都要出現，不可省略。
- 有未結案的區段，再一件一行列出（照「每列格式」），逾期的標出逾期天數。
- 每個區段後面附上實際讀到的分頁名稱（例如「三廠OOS（分頁：三廠-2026年OOS）」），方便確認有沒有抓對分頁。
- 系統寫「讀不到」時，就如實說讀不到、請管理者檢查，不要用舊的資料或自己猜。
- 這份表只能看不能改；有人要改，請他通知表的負責人。
